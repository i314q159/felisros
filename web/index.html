      分发步骤
      
        
        
          
      1. 在 Windows 上用 python app.py 启动，默认监听所有网卡。
        2. 
          
      2. 把上面的分发页地址或安装命令发给局域网内的用户。
        3. 
          
      3. 对方在 Linux 终端粘贴命令即可；脚本自动识别架构、校验 SHA256、安装到用户目录，无需 root。
        4. 
          
      4. 安装后运行 ~/.local/bin/felisros 打开界面。
        5. 
        
      
        
      整个过程没有账号、授权、遥测或回传；安装包可自由复制分发。服务默认监听所有网卡，建议只在可信的局域网内运行；如需仅本机访问，用 python app.py --host 127.0.0.1 启动。

      设备互更新 · 自由分发网络
      
      
      装有 felisros 的 Linux 设备会向局域网广播自己的版本，任何设备都能从有最新版本的设备拉取安装包、校验 SHA256 后自更新。没有账号、授权、中心服务器，也没有遥测。

      自由分发规则
      
        
        
          
      1. 任何 Linux 设备装上 felisros 后，都会成为可分发更新的种子；无需注册或付费。
        2. 
          
      2. 局域网里的设备自动互相发现版本；版本号更高的一方自动成为更新源。
        3. 
          
      3. 更新包下载后先校验 SHA256，再原子替换程序目录，并保留最近三份备份。
        4. 
          
      4. Windows 端只作控制端：不安装、不更新自身，但可以批量把更新推送给 Linux 设备。
